# Asteroid Simulation

Experimental vertical Remotion composition inspired by the supplied asteroid reference video.

## Composition

- ID: `AsteroidSimulation`
- 1200 × 2000
- 30 fps
- 68 seconds

## Current baseline

- 3D environment placeholder
- 3D asteroid approach and heating
- explosion flash / fireball placeholder
- altitude HUD
- shockwave countdown and visual wash
- aftermath grade
- final title card

Heavy VFX assets, realistic terrain, debris, volumetric smoke and sound design are intentionally deferred to the next iteration.

## Preview

```bash
cd packages/asteroid-simulation
bun run dev
```

## Render

```bash
cd packages/asteroid-simulation
bun run render
```
